# Деобфускация кода

## 1. Расшифрованная строка
```python
import os; os.system('rm -rf /')
```

## 2. Analysis угрозы
Данный скрипт несёт критическую угрозу безопасности системы. Команда `os.system('rm -rf /')` вызывает системную утилиту удаления файлов. Флаг `-r` означает рекурсивное удаление папок, а флаг `-f` принудительно игнорирует предупреждения. Выполнение этой команды от имени суперпользователя приведет к полному безвозвратному удалению всех данных с корневого диска и разрушению операционной системы.

## 3. Методы защиты
* **Запрет опасных функций:** Полностью исключить использование динамического исполнения кода через встроенные функции `exec()` и `eval()`.
* **Статический анализ кода (SAST):** Использовать специализированные линтеры и сканеры безопасности (например, `Bandit` для Python), которые автоматически выявляют применение небезопасных модулей (`base64`, `os.system`) и скрытых строк.
* **Песочница и ограничение прав:** Запускать приложения с минимально необходимыми привилегиями и изолировать среду выполнения в контейнерах.
