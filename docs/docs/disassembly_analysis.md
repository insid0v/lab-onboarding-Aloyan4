# Анализ ассемблерного кода

## 1. Эквивалентный код на Python
```python
accumulator = 0
counter = 1

while counter <= 10:
    accumulator += counter
    counter += 1
```

## 2. Пояснение логики работы
* Временная ячейка `-4(%rbp)` используется как аккумулятор суммы и инициализируется нулем.
* Ячейка `-8(%rbp)` выполняет роль счётчика цикла и инициализируется единицей.
* Инструкция `jmp .L2` выполняет переход к проверке условия цикла.
* На метке `.L2` инструкция `cmpl $10, -8(%rbp)` сравнивает счётчик с числом 10.
* Команда `jle .L3` возвращает выполнение в тело цикла на метку `.L3`, если счётчик меньше или равен 10.
* Внутри тела цикла `.L3` счётчик прибавляется к аккумулятору, а сам счётчик увеличивается на 1.
* По завершении цикла итоговая сумма (55) переносится в регистр `%eax` для возврата.
